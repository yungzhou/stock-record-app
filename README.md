# 股票買賣紀錄 App v2.1：股票代號欄位直接搜尋版

## 介面調整
- 移除獨立的「搜尋股票代號或名稱」欄位
- 直接在「股票代號」欄位輸入代號或部分代號
- 輸入時立即顯示搜尋建議
- 選擇結果後，代號保留在股票代號欄位
- 股票名稱欄位自動填入完整名稱
- 商品類型仍會自動辨識為股票或 ETF
- 找不到時仍可手動輸入代號與名稱

## 操作範例
- 輸入 2330 → 下方顯示 2330 台積電 → 點選後名稱欄填入台積電
- 輸入 23 → 下方列出 2303、2308、2317、2330 等建議
- 輸入 AAPL → 名稱欄填入 Apple Inc. - Common Stock
- 輸入 NV → 下方列出 NVDA 等建議

## 保留功能
- 台股、美股與 ETF 離線名單
- 官方股票名單更新按鈕
- 多幣別帳戶
- 美元換匯成本
- 美元平均換匯成本
- 換匯明細
- 資產走勢
- JSON 備份與 CSV 匯出
- 夜間模式與字體大小
